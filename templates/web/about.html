About CVForge

What is CVForge?

CVForge is an intelligent CV generation system that helps you create tailored, ATS-compliant resumes for specific job applications. Using AI-powered content selection and rewriting, CVForge analyzes job descriptions and automatically highlights your most relevant experience and skills.

Key Features
  • Intelligent Content Selection: Automatically selects the most relevant achievements based on job requirements
  • AI-Powered Tailoring: Rewrites content to match job descriptions while maintaining authenticity
  • Job Description Analysis: Extracts key requirements, skills, and keywords from job postings
  • LinkedIn Integration: Fetch job descriptions directly from LinkedIn URLs
  • ATS-Compliant PDFs: Generates professional, ATS-friendly PDF resumes
  • Achievement Memory Helper: Interactive tool to help recall and document past accomplishments
  • CV Validation: Checks data completeness and quality
  • Multiple LLM Providers: Supports Claude API and local Ollama models
Technology Stack
  • Backend: Python, Flask
  • Data Validation: Pydantic V2
  • AI/LLM: Anthropic Claude API, Ollama
  • PDF Generation: WeasyPrint
  • Web Scraping: BeautifulSoup4, Selenium
  • Frontend: Bootstrap 5, Jinja2 templates
How It Works
  1. Store Your Data: Maintain a comprehensive YAML file with all your experience, skills, and achievements
  2. Input Job Details: Paste a job description or provide a LinkedIn URL
  3. AI Analysis: The system analyzes requirements and scores your achievements for relevance
  4. Content Selection: Automatically selects the most impactful experiences and skills
  5. Tailored Rewriting: AI rewrites content to align with the job while maintaining authenticity
  6. Preview & Refine: Review the tailored CV and make adjustments if needed
  7. Generate PDF: Download a professional, ATS-compliant PDF resume
Privacy & Data

Your CV data is stored locally in YAML format. When using AI features, content is sent to the configured LLM provider (Claude API or local Ollama). No data is stored on external servers beyond the LLM API calls. You maintain full control over your data.

Open Source

CVForge is open source software. Contributions, bug reports, and feature requests are welcome!
